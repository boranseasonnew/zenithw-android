## ✨ Features

**ZenithW Android** is a modern media downloader powered by **yt-dlp**, designed to make downloading videos, audio, subtitles and metadata as simple as possible.

### 🔗 Simple URL Downloads

Just paste a supported media URL into the application and choose your preferred download options.

No complicated commands, scripts or terminal usage are required.

### 🍪 Automatic Cookie Import

ZenithW can automatically obtain and configure cookies from a provided account/session connection.

You only need to provide the required connection information and the application handles the cookie configuration automatically.

This can be useful for content that requires authentication or an active session.

### 🛡️ Privacy-Friendly Downloads

Downloads are performed directly from **your own device** using **your own internet connection and IP address**.

There is no remote download server sitting between you and the media source.

- No advertisements
- No tracking-based download system
- No mandatory account
- No external download server

Your downloads stay on your device.

### ⚙️ yt-dlp Engine Management

ZenithW includes built-in management for the yt-dlp engine.

You can:

- 🔄 Update yt-dlp directly from the application
- 📦 Choose between different yt-dlp release channels
- 🟢 Use the **Stable** version
- 🌙 Use the **Nightly** version
- 🔧 Change the preferred yt-dlp engine/version

> **Recommended:** The **Nightly** version of yt-dlp is generally preferred because it receives extractor fixes and website compatibility updates faster.

### 🚫 SponsorBlock Support

Skip unwanted sections automatically using **SponsorBlock** integration.

Depending on your configuration, supported segments can be removed during processing.

### 🎵 Audio Downloads

Download audio in multiple formats, including:

- M4A
- MP3
- OPUS
- Other yt-dlp supported audio formats

You can also extract audio directly from videos.

### 🎬 High-Quality Video Downloads

Download videos in the highest available quality supported by the source.

Supported resolutions may include:

- 720p
- 1080p
- 1440p
- 4K
- 8K

Actual available quality depends on the original video.

### 📚 Download Queue

Add multiple downloads to a queue instead of waiting for each one individually.

This makes it easier to prepare several videos, playlists or audio downloads and let ZenithW process them one by one.

### 🖼️ Thumbnail Embedding

Automatically download and embed video thumbnails into supported media files.

Useful for music libraries, downloaded videos and media players that display embedded artwork.

### 💬 Subtitle Downloads

Download available subtitles together with your media.

Options can include:

- Original subtitles
- Automatically generated subtitles
- Multiple subtitle languages
- Subtitle-only downloads

Availability depends on the source platform and video.

### 📁 Metadata Support

ZenithW can preserve and embed supported metadata such as:

- Video title
- Artist / uploader
- Thumbnail
- Description
- Upload information
- Other available media metadata

### ⚡ Powered by yt-dlp

ZenithW uses **yt-dlp** as its core download engine, giving it compatibility with a large number of supported websites and media platforms.

Because website extractors frequently change, keeping yt-dlp updated is strongly recommended.

## 🚀 And More

ZenithW includes many additional download, conversion and media-management options designed to make yt-dlp easier to use on Android without needing command-line knowledge.

More features and improvements may be added in future releases.
