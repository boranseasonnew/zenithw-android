ZenithW 3.1.1 is a hotfix for Android 7.0 and later.

- The download configuration opens with compact video, audio and subtitle controls. Advanced settings scroll independently of the download actions.
- Downloads reuse valid preview information. Expired media links can refresh once, and a failed optional subtitle no longer prevents saving the media. Subtitle-only downloads still report the failure and its HTTP status.
- Temporary network failures use bounded retries. Deleted sessions are reported before the app makes a source request. Queue availability and cancellation are checked before work moves to file publication.
- Paste and the download icon sit at the bottom right of the home screen. Download engine controls are the first category in Settings. About explains the project, privacy and Android features in Turkish, English, German, French and Russian.

Choose the APK for your device architecture. The GitHub release uses the existing signing certificate so it can update an installed GitHub stable build. Compare the APK with `SHA256SUMS.txt` to verify the download.

Native compatibility with 16 KB memory-page devices remains unverified. The separate F-Droid edition uses its bundled engine and is subject to the existing packaging review.
