## What's Changed

Zenith Android 3.0.0 adds a browser-compatible HTTP/TLS transport for Pornhub requests and improves the saved-session workflow.

- Use an independently implemented native browser transport for metadata analysis and the regular download command. The selected cookies, captured User-Agent, proxy and IP-family preferences are preserved.
- Keep the download configuration open when changing or importing a session. Reanalyze the source with that session while retaining the selected download options.
- Cancel the native network process together with its owning analysis or download process. Apply bounded requests, response-size limits and individually checked redirects.
- Retain certificate verification and recalculate scoped cookies for each redirect. Source cookies are not forwarded to unrelated CDN domains.
- Add safe runtime diagnostics without logging cookies, tokens or signed media links.
- Verify pinned native executables and complete dependency notices during packaging, and verify the packaged bytes again before publication.

## Validation

The Android 13 and Android 7 test candidates reproduced HTTP 403 with the previous network path, then successfully extracted real metadata through the new transport. They also downloaded a 10,241-byte sample from the actual source using the existing downloader. Controlled tests cover metadata and CLI downloads, selected cookies, captured User-Agent, TLS verification, redirect boundaries and cancellation. The adapter also passed its API checks with nightly yt-dlp 2026.10.29.232701.

The release workflow builds and signs the arm64-v8a, armeabi-v7a and x86_64 APKs using the retained stable signing certificate. SHA-256 checksums are included in `SHA256SUMS.txt`.

## Requirements and Known Limits

- Android 7.0 or later (API 24+). Install the APK matching your device architecture over the existing stable app to retain its data.
- Physical-phone VPN/account combinations and a complete real-source video download have not been verified. The actual-source checks used metadata and a small media sample.
- Full native compatibility with 16 KB memory-page devices has not been established. The pinned upstream browser executables have 4 KB ELF alignment.
- Source availability and access requirements can change independently of the app.
