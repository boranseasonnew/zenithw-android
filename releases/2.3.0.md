## Türkçe

- Ana ekran sadeleştirildi. İndirme seçenekleri artık video bilgileri beklenmeden açılır; bilgi ve gerçek kaynak biçimleri aynı pencerede arka planda yüklenir.
- Analiz ve oynatma listeleri artık proxy, IP ve kullanıcı aracısı tercihlerini kullanır. Kısa analiz sınırı, daha uzun tekrar deneme ve güncelleme kontrol aralığı eklendi. Henüz cihazlar arası ölçülmüş bir hız artışı yüzdesi yoktur.
- Kaynak biçimi seçimi, dosya adını değiştirme, kesit indirme ve kaynakta bulunan altyazı dilleri eklendi.
- Sağ üstteki terminal simgesi altında Toplu / Komutlar / Günlük sekmeleri bulunur. + ile bağlantı satırı eklenebilir; yt-dlp şablonları kaydedilebilir, görev günlükleri izlenebilir, kopyalanabilir, iptal edilip yeniden başlatılabilir.
- Sistem/açık/koyu/dinamik tema; seçimleri hatırlama, önizleme ve geçmiş tercihleri; çıktı klasörü, ayrı ses/video klasörleri, dosya boyutu sınırı ve biçim sıralaması eklendi.
- Seal 1.13.1 davranış ve tasarım referansı olarak incelendi. Seal kaynak kodu veya görselleri APK'lara taşınmadı. Ayrıntılar README ve THIRD_PARTY_NOTICES.md dosyalarında; Zenith kaynak lisansı AGPL-3.0-only olarak korundu.
- APK'lar mevcut imza anahtarıyla GitHub Actions üzerinde derlenir. Yayınlama, paket/imza doğrulaması ve Android 13/7 test adımları başarılı olduktan sonra yapılır. Fiziksel cihazlar ve 16 KB sayfa boyutlu cihazlar için tam uyumluluk iddiası yoktur.

## English

- Simplified the home screen. Download configuration now opens before metadata is ready, with media details and real source formats loading in the same sheet.
- Discovery and playlists now respect proxy, IP-family and user-agent preferences. Added bounded fast discovery, an extended retry and an update-check interval. No measured cross-device extraction speedup percentage is claimed.
- Added source-format selection, filename overrides, clip downloads and available subtitle languages.
- The top-right terminal icon opens Batch / Commands / Log. Add URL rows with +, save yt-dlp templates, inspect/copy task logs, cancel tasks and restart them.
- Added system/light/dark/dynamic appearance, remembered-choice/preview/history preferences, output-folder selection, separate audio/video folders, file-size limits and format sorting.
- Seal 1.13.1 was studied as a behavioral and design reference. Seal source or visual assets were not bundled in these APKs. See README and THIRD_PARTY_NOTICES.md; Zenith's own source remains AGPL-3.0-only.
- APKs are built with the existing signing key by GitHub Actions. Publication follows successful package/signature verification and Android 13/7 test steps. Full physical-device or 16 KB-page compatibility is not claimed.
